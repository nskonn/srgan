# SRGAN: Super-Resolution Generative Adversarial Network

Реализация нейросети для увеличения разрешения изображений в 4 раза на основе архитектуры SRGAN.

## !!! Добавить пример работы 

## 📌 Особенности
- Генератор с остаточными блоками (16 Residual Blocks)
- Дискриминатор с глубокой сверточной архитектурой
- Перцептуальные потери на основе VGG19
- Поддержка обучения на GPU/CUDA
- Скрипт для инференса с преобразованием отдельных файлов

# 🧠 Архитектура проекта
```
srgan-project/
├── models/
│   ├── generator.py       # Архитектура генератора
│   ├── discriminator.py   # Архитектура дискриминатора
│   └── residual_block.py  # Остаточные блоки
├── losses/
│   └── vgg_loss.py        # Реализация VGG-потерь
├── utils/
│   ├── trainer.py         # Логика обучения
│   ├── logger.py          # Визуализация прогресса
│   └── config.py          # Настройки параметров
├── data/                  # Датасеты (не включено в репозиторий)
├── outputs/               # Результаты работы модели
└── train.py               # Основной скрипт обучения
```


## ⚙️ Установка

1. Установка зависимостей:
```bash
pip install -r requirements.txt
```

2. Обучение модели

- 2.1 Необходимая структура папок для обучения:
```
src/data/
├── train/
│   ├── lr/  # Изображения низкого разрешения
│   └── hr/  # Соответствующие изображения высокого разрешения
└── val/
    ├── lr/
    └── hr/
```

- 2.2 Запуск обучения:
```
python train.py --data_dir ./data --epochs 100 --batch_size 16
```

- 2.3 Тестирование
```
python test.py --model generator.pth --test_dir ./data/val
```

- 2.4 Улучшение изображения
```
python inference.py --input input.jpg --output enhanced.jpg
```
